# 📉 Customer Churn Analysis & Prediction

> An end-to-end data science project to predict and reduce customer churn in the telecom industry — from raw data to machine learning models and interactive business intelligence dashboards.

---

## 🎯 Project Goal

This project aims to:
- **Predict** which telecom customers are at risk of churning using Machine Learning
- **Reduce customer churn** by uncovering key drivers and behavioral patterns
- **Deliver actionable insights** through an interactive Power BI dashboard
- Provide a **complete pipeline**: raw data → SQL staging → Python ML model → BI reporting

---

## 🛠️ Tools & Technologies

| Tool | Purpose |
|------|---------|
| 🐍 Python (Jupyter Notebook) | Data preprocessing, EDA, ML modeling |
| 🗄️ SQL | Data extraction and staging (Stg_Churn) |
| 📊 Power BI | Interactive dashboard & visual reporting |
| 📁 Excel | Raw data storage (Prediction_Data.xlsx) |
| 🤖 Machine Learning | Churn prediction model |

## 🚀 How to Run

1. **SQL**: Run `SQLQuery1 (Stg_Churn).sql` to stage the data
2. **Python**: Open `Churn Prediction.ipynb` in VS Code or Jupyter
3. **Power BI**: Open `Telecom Customer Churn Analysis.pbix` in Power BI Desktop
